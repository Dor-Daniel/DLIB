# Manifest

* This library should be platform specific **Windows** only (because this is only for me so I need to do it as simple as possible for now [maybe later add abstract layer for platform agnostic]).
* Every file should be self contained. meaning users (Future me) should be able to include any header and it just works no need to include others.
* I should follow strict design rules in order to maintain a readable code and easy to use one.
* All methods should be named using a consistant way for example using create or new but not both.
